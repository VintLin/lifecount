# LifeCount 视觉模式

2026-11-18。正式页面提供 `grid`、`hourglass`、`candle`、`daylight`，由 `src/data/lifecount.ts` 的唯一列表定义。

## 页面与数据

Header 视图按钮位于设置左侧，菜单勾选在右侧。沙漏替换网格内容区域，沿用白底；提供原生全屏及不支持时的窗口内全屏，Escape 退出。无演示拖杆、加速播放和固定 35% 初值。

沙漏普通视图额外顶部留白为 24px，640px 及以下为 16px。全屏在原有留白之上增加 32px，并同步减少画布可用高度，保持底部完整；原生与窗口内全屏共用规则。

```text
现有设置与缓存 → VisualModeController → 秒数快照 → HourglassRenderer
                      │                            ├─ 静态玻璃图
                      └─ 网格 / 沙漏切换             ├─ 按真实进度分配上下腔体积
                                                   └─ 感知沙流与局部沉降
```

出生日期和最高年龄只来自现有设置。时间边界沿用 `parseDay` / `anniversary`，以秒计算已过去、剩余和比例，并限制到 0–1。网格仍按完整日/周/月/年格统计，其舍入与秒数比例可能略有差异。名人履历强制显示网格，返回“我”恢复所选视图。有效视觉模式随设置缓存恢复，未知模式回退 grid。

## 唯一正式实现

- `src/scripts/lifecount-visual.ts`：菜单、时间快照、1Hz 文本、设置/语言联动、暂停与资源释放。
- `src/scripts/visuals/hourglass.ts`：原生 Canvas 2D；已验收的轮廓、黑沙和表面规则。静态粒子池随量化人生进度更新；单个模拟粒子不是一秒。
- `public/images/hourglass-glass.png`：获用户确认的生成玻璃底稿，按需加载，无 Base64 副本。
- `public/licenses/aether-sand.txt`：粒子运动思路参考的来源声明；非整套第三方沙盒导入。

上腔是守恒数量的整体沉降近似，中心最多约四个模拟像素浅凹。下腔保留局部坡面和短距离沉降，禁止同高度颗粒交换，受支撑后速度归零。沉降结束不再计算沙堆。细沙流是有限的感知动画，不参与扣减上腔或增加下腔，不会在数分钟内消耗用户寿命。

沙体绘制与模拟网格分离：提取上下腔连续受支撑的自由沙面，用局部加权平均和二次曲线构建轮廓，并在显示画布的设备像素分辨率下裁切绘制。起点位于玻璃的列不参与自由沙面端点拟合；自由沙面向杯壁外延伸，闭合边位于杯外，最后与内壁曲线求交裁切，防止杯内竖切口。固定种子的半格颗粒纹理保留黑沙质感，不消耗模拟的随机序列；不足三格高或不能构成连续沙面的散沙单独绘制。轮廓只在沙粒状态变化时重建，普通沙流帧复用轮廓。

内壁由原素材采样点生成保形三次 Hermite 曲线，内部节点采用加权调和平均切线，半径极值处切线归零，保持切线连续并限制过冲；算法依据见 [SciPy 保形插值说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html#notes)。原生 Canvas 以三次 Bezier 绘制同一曲线。下腔从最宽处 y=405 起，以单段三次 Bezier 连接到 y=462 的内底面：侧壁起点切线垂直，杯底中心切线水平，两侧在中心圆滑连接。原 y=474 的外底座位置不再作为沙子的承托面，底座玻璃反光留在沙体下方。模拟在同一曲线的格子中心采样可用区域，绘制与碰撞共用几何来源。

素材的上腔左右轮廓并非严格镜像：左壁使用独立校准的采样半径，经同一保形插值生成曲线，校准量向颈口平滑归零。模拟分别采样左右壁，再判断格子中心是否处于两壁之间；裁切使用对应两条曲线。左侧贴边验收必须对照摄影素材，不能只证明沙体与程序定义的杯壁相交。

模拟网格精度仍为 220×480。平滑内壁使可用格子容量改变，因此总粒子预算重新计算；上下腔继续按真实进度量化分配，动画不推进人生进度。固定进度与容量变化后的验收见贴壁优化记录。

切换回网格销毁 renderer；设置打开、页面后台和 reduced-motion 暂停动画。后台仍可初始化静态画面，回前台重新读取当前时间，不补播。达到寿命终点后无沙流，短暂沉降后静止。Canvas 不承担可访问数值，秒数以 DOM 文本展示，关闭每秒 live 播报。

## 验收

见 `docs/e2e/lifecount-visual-modes/verification.md`。必须通过生日/最高年龄联动、缓存恢复、中英文、网格切换、名人履历隔离、桌面/手机/全屏、后台/reduced-motion、0%/100%、真实时间不被动画推进及 check/build。

限制：2D 摄影素材合成，没有物理光学折射；细沙流不是逐秒实体模拟。未发布至线上。

## 摘要与时间单位

非网格视图用顶部秒数摘要替代年龄/网格摘要，不在沙漏下方重复显示。单位按钮显示本地化“秒 / Seconds”并禁用，不改变实际网格单位、URL 或缓存。回到网格恢复原单位与年龄摘要。秒数更新时顶部 aria-live=off。


## 天光（Daylight）

直接铺满浏览器内容区域，Header、秒数摘要与设置浮在天空上；不强制隐藏浏览器工具栏。Escape 或视图菜单返回网格。名人履历继续使用网格。

`src/scripts/visuals/daylight.ts` 使用按需载入的 Three.js，在独立 WebGL canvas 上绘制全屏渐变。四组配色随人生进度平滑过渡，按画面高度混色，晨昏辉光方向相反。薄雾缓慢漂移，静态抖动减轻色带。夜间可见稀疏星点。Header 根据日夜使用深/浅字色，菜单和设置维持原有可读样式。

人生比例映射到一天：0% 午夜、25% 日出、50% 正午、75% 日落、100% 午夜。这是人生可视化，不是所在地天气或天文日出时间。生日与最高年龄仍取“我”的缓存设置。薄雾的动画时钟独立于人生进度，不加速消耗生命。

24fps 上限、设备像素比上限 1.5。后台、设置开启、减少动态效果时暂停连续动画；100% 静止。切换视图取消 rAF、断开 ResizeObserver 并释放 WebGL 资源；异步加载完成后检查是否已销毁。WebGL 不可用时保留静态天色与可操作的页面。
